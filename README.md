# El Ojo de Dios

Aplicación Android tipo asistente personal estilo JARVIS, desarrollada como un MVP con IA Gemini.

## Descripción

- Interfaz moderna en Jetpack Compose
- Chat con estilo futurista
- Integración con Gemini API
- Creador: carlosart
- Nombre del asistente: El Ojo de Dios

## Requisitos

- Android Studio Iguana o superior
- JDK 17
- SDK Android 34

## Configuración

1. Abre el proyecto en Android Studio.
2. Haz clic en `Sync Project with Gradle Files`.
3. Agrega tu API key de Gemini en la caja de texto de la app.
4. Ejecuta la app.

## Nota importante

La clave de Gemini no se guarda en el repositorio. Se ingresa desde la interfaz para evitar exponer secretos.
